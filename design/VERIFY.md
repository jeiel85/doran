# 실기기 확인 (릴리스 전)

에뮬레이터 + 가짜 가족 폰(`scripts/fake-peer.mjs`)으로는 확인했지만, 아래는 **실제 두 폰**(남편 Galaxy S24, 아내 폰)으로만 확인할 수 있습니다.
하나라도 실패하면 릴리스하지 않고 고칩니다.

## 설치·연결
- [ ] 남편 폰: 소개 페이지 → APK 받기 → 설치 → "새 가계부 시작하기" → 이름 "남편"
- [ ] 홈의 "배우자를 초대해 함께 써요" → QR이 화면 가득
- [ ] 아내 폰(도란 없음): **기본 카메라**로 QR → 연결 페이지 → "도란이 아직 없어요" 안내 → APK 설치 → "설치했어요 · 연결 계속하기" → 도란이 열리며 "남편님이 보낸 초대" → 이름 "아내" → 연결하기
- [ ] 아내 폰(도란 있음)으로 새 QR을 찍으면 페이지를 거쳐 바로 도란이 열림
- [ ] 링크를 카카오톡으로 보내 눌러도 같은 흐름
- [ ] 가족 화면 "연결된 기기"에 남편·아내 이름이 보임

## 알림 자동 기록 (남편 폰)
- [ ] 알림 자동 기록 → 알림 접근 켜기. "제한된 설정"으로 막히면 앱 정보 ⋮ → 제한된 설정 허용 → 다시 켜기
- [ ] 배터리 사용 제한 없음 켜기
- [ ] 현대카드로 실제 결제 → 남편 폰 홈 "새로 들어온 내역"에 가맹점·금액·누적
- [ ] 같은 결제의 문자도 오면 한 건으로 합쳐짐
- [ ] **현대카드 앱 알림 원문**을 "최근에 읽은 알림"에서 확인해 해석 결과가 맞는지 기록(틀리면 원문을 가려서 ParserTest에 추가)
- [ ] 승인 취소 알림 → 원래 결제가 취소선, 합계에서 빠짐

## 골라 보내기 (0.1.2)
- [ ] 목록에 없는 곳의 결제 알림(지역 카드·간편결제)이 오면 홈에 "기록되지 않은 금액 알림 1건" → 보기 → 골라서 보내기 → 카드사 이름 확인 → 보내기 → 장부와 아내 폰 알림
- [ ] "앞으로도 자동으로 보내기"를 켠 뒤 같은 곳의 다음 결제는 저절로 기록, 알림 자동 기록 화면의 "자동으로 보내는 발신처"에서 그만두기
- [ ] Play 버전: 문자 권한 없이 카드 문자가 문자 앱 알림으로 기록됨(대화방 알림이 켜져 있을 때)

## 공유 범위 (0.1.3)
- [ ] 아내 폰: 가족 → 남편 → "정한 결제만 보내기" · 현대카드 · 월 용돈 350,000 → 저장 → 남편 폰에 "아내가 내 공유 범위를 바꿨어요" 알림
- [ ] 남편 폰: 현대카드 결제 → 아내 폰 알림·가계부 / 다른 카드·현금 인출 → 남편 폰에만 🔒 용돈, 아내 폰에는 "남편 용돈" 월 합계만, 자산에 그 카드·계좌가 생기지 않음
- [ ] 남편 폰에서 "함께 관리"로 되돌리면 아내 폰에 "남편이 공유 범위를 바꿨어요"

## 아내 폰에 오는 알림
- [ ] 위 결제 직후 아내 폰에 "남편이 현대카드로 ○○원 썼어요 / 가맹점 · 카드사 누적 ○○원" (Firebase 설정 시 몇 초 안, 없으면 15분 안)
- [ ] 알림을 누르면 그 내역이 열림
- [ ] 아내 폰에 "문자 자동 전달" 앱으로 넘어온 같은 문자가 와도 두 번 기록되지 않음
- [ ] 화면이 꺼진 아내 폰에서도 알림이 옴(삼성 절전)

## 업데이트
