개인정보 처리 안내

도란은 가족끼리 쓰는 가계부예요. 아래는 어떤 정보를 어디에 두는지에 대한 설명이에요. (2026-11-17)

폰에만 있는 것

  • 장부 전체(내역·계좌·예산·목표 등)와 영수증 사진 — 폰 안의 앱 저장소에 둬요. 안드로이드 자동 백업으로 옮기지 않아요.
  • 읽은 카드·은행 알림 원문 — 형식 점검용으로 그 폰에만 30일 남기고 지워요. 금액·승인 형식이 아닌 알림은 읽자마자 버려요.
  • 암호 키 — 안드로이드 키 저장소로 한 번 더 감싸 둬요.

중계 서버(Cloudflare)에 있는 것

  • 장부 변경 기록과 영수증 사진의 암호문. 가족 폰에서 만든 키로 암호화돼 서버는 금액·가맹점·이름을 볼 수 없어요.
  • 기기 id, 접속 토큰의 해시, 알림용 FCM 토큰, 어느 기기가 어느 가계부에 연결됐는지, 각 기록의 크기와 시각.
  • 가계부에서 모든 가족 기기가 빠지면 그 가계부의 기록은 지워져요.

Google(FCM)

새 기록이 있다는 "깨우기" 신호만 보내요. 금액·가맹점은 담기지 않고, 알림 문장은 폰이 기록을 푼 뒤 만들어요.

GitHub

앱 업데이트 확인을 위해 하루 두 번 GitHub 릴리스 정보를 읽어요. 장부 내용은 보내지 않아요.

권한

  • 알림 접근·문자 받기: 카드·은행 알림을 장부에 기록하려고 써요.
  • 카메라: 가족 연결 QR과 영수증 사진을 찍을 때만.
  • 알림 표시: 가족 내역·예산 알림.
  • 앱 설치: 도란 스스로 업데이트할 때만.

지우기

앱을 지우면 폰의 장부가 지워져요. 가족 화면에서 기기를 내보내면 그 기기는 더 이상 장부를 받을 수 없어요.
